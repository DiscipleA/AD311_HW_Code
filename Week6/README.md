# Assignment AD311: Building React Applications with Different Frameworks

## 📂 Projects Overview
This repository contains four small React applications built with different frameworks:
- Next.js (web)
- Remix-style React Router (Remix successor) (web)
- Gatsby (web) *(setup encountered tooling issues in some environments)*
- Expo (mobile)

Each project demonstrates common React app patterns: routing, data fetching, and framework-specific features.

---

## 🚀 How It Works

### 1) Next.js
- Uses the App Router (`app/` directory).
- Landing page uses shared layout (`app/layout.tsx`) and page content (`app/page.tsx`).
- Dynamic route: `/users/[id]` fetches profile data from JSONPlaceholder.
- Static generation: landing page is statically generated by default; dynamic routes can be prebuilt via `generateStaticParams()`.

### 2) Remix (React Router Framework Mode)
> Remix v2 is now part of React Router; new projects are created with `create-react-router`.
- Uses file route modules + `app/routes.ts` route config.
- Blog homepage lists posts.
- Individual post route loads content by slug.
- Markdown posts are read from local `.md` files and pre-rendered at build time using React Router prerendering.
- Nested routing implemented with Tags: `/tags` + `/tags/:tag` rendered via a parent layout route using `<Outlet />`.

### 3) Gatsby
- Gatsby project created with `create-gatsby`.
- Intended: use Gatsby’s data layer + content sources (Markdown/Contentful).
- Note: Gatsby can be sensitive to Node/plugin versions; if you encounter LMDB/typegen issues, pin/override dependencies or disable typegen. Continue once `gatsby develop` runs successfully.

### 4) Expo
- Mobile app built with Expo.
- Bottom tab navigation includes Home and About.
- Home tab fetches coin market data from CoinGecko and displays a list.
- Notifications: the app requests permissions and triggers a notification when new items are detected or simulated.

## ✨ Features

### Next.js
- Header + sections + footer landing page
- Sticky header, CTA buttons, card UI, responsive services grid
- Dynamic user profiles from JSONPlaceholder (`/users/[id]`)
- Build-time static generation support

### Remix / React Router (Framework Mode)
- Blog homepage + post pages
- Markdown-based content source
- Build-time pre-rendering of blog routes
- Nested routing for Tags using `<Outlet />`

### Gatsby
- Gatsby starter project setup
- (Optional) Markdown support / Contentful source integration
- Static site generation with Gatsby build pipeline

### Expo
- Tab navigation (Home/About)
- API fetch list on Home screen
- Local notifications when new items are added (or simulated)

## 🛠️ How To Run

### Next.js
```bash
cd next-framework-assignment
npm install
npm run dev
# http://localhost:3000
```

### Remix / React Router (Framework Mode)
```bash
cd remix-framework-assignment
npm install
npm run dev
# usually http://localhost:5173
```
Build + start (pre-render):
```bash
npm run build
npm run start
```

### Gatsby
```bash
cd gatsby-framework-assignment
npm install
npm run develop
# http://localhost:8000
```
Production build:
```bash
npm run build
npm run serve
```

### Expo
```bash
cd expo-framework-assignment
npm install
npm start
```
Run on phone via Expo Go or on an emulator/simulator.
