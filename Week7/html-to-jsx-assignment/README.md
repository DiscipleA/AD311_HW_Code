# Assignment AD311: HTML to JSX Conversion

## 📂 Project Overview
This project demonstrates the conversion of static HTML markup into a modular, reusable React functional component. It focuses on JSX syntax rules, prop handling, and component testing.

## 🚀 Features
- **Functional Component:** `UserProfile` component built with React.
- **Dynamic Data:** Uses React Props to display user information (Name, Email, Photo).
- **JSX Best Practices:** Implements `className`, self-closing tags, and single-parent encapsulation.
- **Comprehensive Testing:** Includes a suite of Vitest unit tests covering normal and edge cases.

## 🛠️ How it Works
1. **App.jsx**: Acts as the parent container that passes data to the child component.
2. **UserProfile.jsx**: Receives data via `props` and renders the UI using JSX expressions.
3. **Vitest**: Validates that the UI updates correctly based on the data passed.

## 📦 How to Run

### 1. Clone the Repository, and then:
```bash
cd react-modularity-assignment
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```

### 4. Run Tests
```bash
npx vitest
```
